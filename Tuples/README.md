Tuple

A tuple is a built-in Python data structure used to store multiple items in a single variable.
Tuples are ordered, immutable (cannot be changed after creation), and allow duplicate values. 
They can store different data types such as integers, strings, floats, and boolean values.

This folder contains Python programs covering tuple basics, indexing, slicing, built-in functions, tuple methods, packing and unpacking, nested tuples, and practice programs. 
It demonstrates common tuple operations such as accessing elements, traversing tuples, counting occurrences, finding element indexes, sorting tuples, concatenating and repeating tuples, converting between lists and tuples, finding the largest and smallest values, calculating the sum and average, and solving beginner-friendly practice problems to strengthen Python programming skills.
