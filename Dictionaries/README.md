Python Dictionaries

Introduction

A dictionary is one of the most powerful built-in data structures in Python. It stores data in the form of key-value pairs, allowing fast searching, updating, and retrieval of data. Dictionaries are widely used in real-world applications such as student management systems, contact books, inventory management, banking systems, and APIs.

Definition

A dictionary is a mutable, unordered collection of key-value pairs. Each key in a dictionary must be unique, while values can be of any data type and may be duplicated.

Syntax

student = {
    "name": "Savitha",
    "age": 22,
    "branch": "CSE"
}

Features

• Stores data as key-value pairs.
• Mutable (items can be added, updated, or removed).
• Keys must be unique.
• Values can be duplicated.
• Supports different data types.
• Fast lookup using keys.
• Can contain nested dictionaries.
• Supports dictionary comprehension.
• Dynamic in size.
• Efficient for searching and updating data.
